## Fluso Cloud

Fluso Cloud is the standard managed service. Fluso operates the application, Agent runtimes, storage, and platform updates. You manage your files, connected apps, and approval settings.

The desktop and mobile apps connect to this service. Installing them does not run the workspace or inference locally. See [current availability](/resources/availability).

Workspace data is hosted in Europe by default. Model inference and connected apps have separate processing boundaries. Pro includes optional [encrypted inference](/features/confidential); this protects model requests without moving the whole workspace into an enclave.

## Custom Enterprise deployments

Contact the team to assess a dedicated VPC or on-premises requirement. These are scoped engagements, not self-service options included automatically with a Cloud subscription.

Before relying on a proposed deployment, agree on:

| Area | What to confirm |
| --- | --- |
| Infrastructure | Supported environment, region, and who operates it |
| Data | Storage, backups, retention, deletion, and support access |
| Models and tools | Inference endpoints, connected systems, and outbound network access |
| Identity and audit | Required identity integration and audit records, including implementation scope |
| Operations | Updates, monitoring, recovery, and support responsibilities |

A private deployment does not automatically make external inference or app connections local. An offline or air-gapped requirement needs a specific design and confirmed feature scope.

For a custom deployment, [contact Fluso](mailto:sales@premai.io). For the standard service's policies, see [Legal](/resources/legal).
