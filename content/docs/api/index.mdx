Use the API to send a message, attach a document, or run a saved Agent. Your integration uses the same workspace as the Fluso app.

Start with one conversation. Add schedules, connections, or live updates when your application needs them.

<Card title="Send your first request" icon="arrow-right" href="/api/first-request">
  Get access, submit a short task, and read the saved answer.
</Card>

## Base URL and access

Send requests to `https://api.fluso.ai/v1` with a [developer token](/api/cloud/tokens). Fluso Dev uses `https://api.dev.khichdi.cc/v1`. Use credentials from the same environment as the URL.

## Find the exact fields

Open **Settings → Developer tokens → API reference** in Fluso.

Releases with this API serve the endpoint reference at `/docs` and the OpenAPI schema at `/v1/openapi.json`. These describe the fields and operations available in that deployment. The reference also supplies runnable examples under `/v1/examples/`.

The guides below explain how to combine those operations. Endpoint tables sit inside each guide, after the main workflow.
