The sidebar is the list of everything you have ever asked Fluso. After a few weeks that list is long, so it is built to be organised rather than scrolled.

Three tools do most of the work: projects for what belongs together, labels for what cuts across, pins for what you need today.

## Projects

A project is a folder with a memory. Chats inside it share files and context, and each project keeps its own notes about how you work there, separate from every other project. See [Memory](/features/memory) for what it remembers.

Give one an icon and a colour and it stops being another grey row. There are 20 icons and 9 colours.

## Labels

Labels are the cross-cutting layer. A chat lives in exactly one project, but it can carry as many labels as you like.

Make one from any chat's `⋯` menu: **Add to label → New label**, give it a name and a colour, and it exists from then on. It shows as a coloured badge beside the chat name, and the same submenu ticks it on and off afterwards.

**Projects take labels too.** Label a folder and the whole folder turns up under that label, its chats with it, which is how a label ends up meaning "everything to do with this" rather than a list of chats you remembered to tag.

Switch the sidebar to **By Label** and the list regroups entirely: one section per label, with a chat appearing under each label it carries.

Deleting a label deletes the label. The chats and projects that carried it stay exactly where they were, minus one badge.

## Pins

Pin what you are on this week and it moves to a **Pinned** section at the top. It is in the `⋯` menu, or `P` while that menu is open. Projects pin the same way, and a pinned folder keeps its chats under it.

Unpinning has three routes, which is one more than most people find: the same `⋯` menu now reads **Unpin**, a crossed-star button appears on the pinned row itself when you hover it, and dragging the row out of the section drops the pin where it lands.

Drag pinned rows against each other to set their order.

## Drag and drop

Project folders drag too. Pull one above or below another to set the order of the tree, or drag it up into **Pinned** and drop it there to pin the whole folder.

**Archived** is a drop target the same way. Drag a chat or a folder down onto it to file the thing away, and drag it back out to bring it in again.

In the **By Label** view the label sections are drop targets as well: a chat dropped on a label picks it up, and one dragged out of a label section loses it. The Projects tree shows no label sections, so reach for the `⋯` menu there instead.

<Note>
  A chat cannot be dragged from one project into another. Projects keep separate memory, and a chat contributes notes to the project it was started in; moving it would leave those notes behind and mix them into somewhere they do not belong. Start the chat where it belongs, and use labels for anything that cuts across.
</Note>

## Making things from the sidebar

The **Projects** header carries a `+` for a new project, and every folder row has one for a new chat inside it. Right-click any empty space in the list for the same two, whichever is nearer your pointer.

## Grouping, filtering, sorting

The filter button above the list controls how the whole sidebar is arranged.

| Control | Options |
| --- | --- |
| Group by | Projects, Recents, Date, By Label |
| Status | All, Active, Error |
| Active within | 24h, 3d, 7d, 30d |
| Sort | last activity newest or oldest, A to Z, Z to A |

**Projects** is the tree you know. **Recents** drops the folders and gives you a flat list of what you touched last. **Date** buckets by day. **By Label** is the reference view described above.

## Search that reads the messages

The search box looks inside the conversations, not only at their titles. Search for a phrase you remember saying and you get the chats that contain it, each with the matching line underneath and the words picked out in it. Results stay grouped by project, so you can see which piece of work a hit belongs to before opening anything.

## Reading a chat without opening it

Rest the pointer on a row for a moment and a card appears with the project it belongs to, how long ago it was touched, the date, and the last of the conversation. Useful when three chats have similar names and you would rather not open all three. Project folders peek the same way, showing what is inside.

## Working on several chats at once

Press and hold a row, or `⌘`-click and `⇧`-click, to start a selection. Every row grows a checkbox and a bar appears at the foot of the sidebar, counting what you have picked and offering the actions that apply to all of it: move, pin, archive, label, delete.

A selection is not confined to one folder. Tick chats in three different projects and the bar treats them as one set, which is the fastest way to clear out a week's worth of scattered one-off chats.

## Renaming, archiving, deleting

Double-click a chat name to rename it in place. Right-click, or click the `⋯`, for everything else.

With that menu open, one key does the job:

| Menu | Keys |
| --- | --- |
| Chat | `P` pin, `R` rename, `S` select, `A` archive, `D` delete |
| Project | `P` pin, `A` archive or restore, `D` delete |
| Label | `R` edit, `D` delete |

Clicking **Delete** opens a confirmation. Holding **Delete** skips it, which is the difference between clearing one chat and clearing twelve.

Archived chats move to their own section at the bottom and stay searchable.

**Share** is in the same `⋯` menu, and beside the chat title at the top of the conversation. Either one gives you a link to hand to someone, and the icon in the header tells you at a glance whether a chat is already shared.

## Getting back to a project

The breadcrumb above a conversation names the project it belongs to. Click that name and the sidebar goes and finds it: it opens if you had it collapsed, expands that folder and closes the others, scrolls it into view, and flashes it once so your eye lands on the right row.

Clicking the chat title beside it renames the chat in place.

## Status at a glance

A mark at the end of a row tells you where that chat stands without opening it: a turning ring while Fluso is still working, a red dot where a run stopped on an error, and a blue one where an answer finished while you were looking somewhere else.

The marks survive a reload, and clear when you open the chat.

## Keyboard

The sidebar takes focus without the mouse. `Esc` from the composer lands you here.

| Key | Does |
| --- | --- |
| `⌘1` to `⌘9` | jump straight to one of your first nine chats |
| `↑` / `↓` | move between rows |
| `←` / `→` | cycle the controls inside the focused row |
| `←` | collapse the folder you are inside, and land on its header |
| `Enter` | open the focused chat |
| `Tab` | step onto the list from outside it |
| `⌘K` | search chats |
| `⌘N` | new chat |
| `⌘B` | hide or show the sidebar |
| `Esc` | back to the sidebar from the composer |

`⌘1` to `⌘9` work while you are typing, so you can leave a half-written message and come back to it.

The arrows only answer while the sidebar actually holds focus, so they never take over the page you are reading. From the search box, `↓` steps down into the first row, which makes `⌘K` a complete route into the list without touching the mouse.

### Width

Tab to the sidebar's inner edge and it becomes a keyboard control.

| Key | Does |
| --- | --- |
| `←` / `→` | narrower or wider |
| `⇧ ←` / `⇧ →` | in bigger steps |
| `Home` / `End` | narrowest or widest |
| `Enter` | back to the default width |

Hidden with `⌘B`, the sidebar leaves a narrow rail behind rather than nothing at all: **New chat**, **Tasks**, **Plugins** and **Projects** stay one click away, and a dot on the rail keeps showing you that something is running or waiting unread.

The full list still answers a hover at the edge: it slides out, you click what you need, and it goes away again. The width you drag it to is remembered, and so is whether you left it open.
