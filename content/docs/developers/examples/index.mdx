Start with the result you need. Give the Agent a small first task before you expand its responsibility or schedule repeat work.

These examples show workflows you can adapt. They are not additional built-in templates.
The available tools depend on your connected apps, permissions, and installed skills.

<CardGroup cols={2}>

    Prepare useful drafts, refine reply rules, and check for a candidate's response.

    Build a searchable contact map, improve its data, and resume a large review.
  </Card>
  <Card title="Customer document filing" icon="folders" href="/developers/examples/document-filing">
    File sent attachments into customer folders and track unresolved items.

Each guide separates the first task, a useful correction, and a repeat workflow.
The checks describe what to inspect in the result. A prompt alone does not guarantee that the Agent completed the work correctly.

For another job, define four things: the input, the result, the allowed actions, and when the work should stop.
Use [Create and refine](/developers/agent-builder) to save that setup.
