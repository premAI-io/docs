title: Improve your Agent
icon: pencil
description: Keep the parts that help, and change the parts that don't.
---

Your first request is a starting point. A few real tasks will show you what you want the Agent to do differently.

## Change the answer in front of you

Use the Agent's conversation for a correction to the current task:

> *"This is more detail than I need before the meeting. Put the decisions first and keep the background to a few lines."*

You can keep working there until the answer is useful.

## Make that your usual way of working

Use **Manager** when you want the Agent to follow that preference in future work.

1. Select the **Edit agent** pencil in the conversation.
2. Choose **Manager** on the setup page.
3. Explain what you want to keep.

> *"For future meeting briefs, put the decisions first. Keep the background short, and finish with three questions I should ask. Save that as my usual format."*

Read the saved instructions beside the conversation. Then return to the Agent and give it another task.

The change applies to its next turn. Work already underway keeps the setup it started with.

## Be specific about what missed the mark

Tell the Manager what happened and what you wanted instead:

> *"The last brief made lunch sound confirmed, but we haven't chosen it. Keep undecided plans clearly marked as open questions."*

This gives it a useful rule to save. You can also ask it to review corrections from the working conversation.

Prefer to make the change yourself? **Edit** opens the saved fields. There is no version-history screen, so explain what to restore if you want to undo a change.

[Settings and app access](/developers/guides/settings) explains the other controls, including response style, files, and connected apps.

<Accordion title="What if work is already running?">
  A new message with changed setup may show **Saved setup applies next turn**. It waits for a separate turn.

  Sessions the Agent already created keep their earlier setup. Give them a correction if they need one. See [Longer tasks and sessions](/developers/guides/conversations).

  A routine keeps its own saved message. Review that message if you change how the Agent should work.
</Accordion>
