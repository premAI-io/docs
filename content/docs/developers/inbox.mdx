Open **Inbox** in the Agents sidebar to see updates across your Agents. The sidebar link opens **All updates**, including routine results. Approvals appear first.

Use **Filters** to select an Agent and show **Approvals & failures**, **Approvals**, **Failures**, **Routine results**, or **All updates**. Resetting filters returns to **Approvals & failures**. A direct Inbox link without filters also opens that attention view.

## Act on the update

| Update | Next step |
| --- | --- |
| Approval | Open the conversation and review the exact action before allowing or denying it |
| Failed run | Read the error and any partial result in the conversation before retrying |
| Routine delivery failure | Open the Agent's routines, check the reason, and fix the target or timing before resuming |
| Routine result | Open the conversation to read the answer and inspect delivered files |

Delegated session completions stay with their conversations rather than filling Inbox. Their pending approvals can still need your attention.

A filtered empty list means there are no matching updates. It does not mean every Agent has finished or all issues are resolved. Inbox shows recent updates, not a complete activity archive.

## What the unread count means

The number beside **Inbox** counts unseen updates in its current recent feed. Opening Inbox in a visible tab marks the displayed updates as seen. If you filter the list, hidden items are not marked seen.

An update that changes can count as unread again. Seeing an approval clears its unread state. It does not approve it or remove the need for a decision.

Read state belongs to this browser and is shared across its tabs. Signing out or switching accounts clears it, and it does not synchronize across devices.

For ongoing work, use the Agent's main conversation or [Sessions](/developers/threads-and-contexts#inspect-sessions-when-useful). For recurring work, see [Routines](/developers/schedules).
