Connectors no longer exist as a separate system. Every app connection in Fluso is now an MCP connection: the same one-click sign-in, managed through **Plugins** in the sidebar, with per-tool permissions on top.

What you used to do here:

- **Connect Gmail, Slack, GitHub, and other apps** — now the **Apps** tab of the Add MCP dialog. Same one-click sign-in on the app's own page. See [Apps and MCP servers](/features/mcp).
- **Per-app setup guides** — unchanged: [Gmail](/integrations/gmail), [Google Calendar](/integrations/google-calendar), [Slack](/integrations/slack), [GitHub](/integrations/github).
- **Disconnect an app** — the connection row's menu on the Plugins page.

Head to [Apps and MCP servers](/features/mcp) for the full picture.
