Open **Plugins → MCP** to connect an app and manage its tool permissions. Native Fluso connectors have the Fluso mark beside their names. You can also add a custom MCP server.

See [Apps and MCP servers](/features/mcp) for setup, Google service connections, and troubleshooting. For a saved Agent, select the connection in its [app access](/developers/guides/settings#grant-app-access) as well.

If the app asks you to reconnect an app you connected before, see [Moving to native connectors](/features/mcp#moving-to-native-connectors).
