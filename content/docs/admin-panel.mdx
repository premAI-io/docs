Fluso Admin is a separate browser interface for authorized operators. A personal Pro or Confidential subscription does not grant administrator access.

Your deployment operator provides the address and assigns a **Read-only** or **Read & write admin** role. The backend checks that role on each admin request.

## Access roles

| Role | Access |
|---|---|
| Read-only | Inspect dashboards, users, runtimes, recorded usage, sponsorship, and network policy |
| Read and write | The same views, plus runtime controls, sponsorship changes, and network-policy changes |

## Current views

| View | What it shows |
|---|---|
| **Overview** | Identity activity, runtime health, plan distribution, recorded usage, and highest-cost users |
| **Users** | Searchable accounts with plan, sponsorship, runtime state, storage, and recorded usage |
| **Runtime fleet** | Runtime status and mapped or unmapped instances; **Refresh fleet** reconciles the snapshot |
| **LLM costs** | Recorded gateway cost and token totals for 30, 90, 180, or 365 days |
| **Network egress** | Origin and provider rules for egress-governed runtimes |

These views do not expose users' messages, project files, or knowledge content. Usage totals describe recorded entries; unavailable data is not evidence of zero usage.

## Runtime and user controls

Open **Users** and select an account. A read-and-write administrator can start, stop, or restart its runtime when the control is available. Active work, warm-up, schedules, or an unhealthy state can block a control. There is no force-stop action.

The storage card reports aggregate usage and limits. It does not open or delete the user's files.

The sponsorship form can grant or extend **Sponsored Confidential**, with an expiry up to 24 months away. Sponsorship changes access, not the person's Clerk subscription or billing schedule.

## Network egress

A read-and-write administrator can create, edit, or delete provider bundles and delete existing Shared rules. The current panel does not add or edit standalone Shared rules.

<Warning>
  These controls apply across egress-governed users, rather than to one organization. A global Deny blocks the origin without an approval prompt. Disabling or deleting a bundle removes its own rules; other global rules and user grants remain.
</Warning>

## Enterprise administration

The current panel does not provide the previously described **Teams & access**, **Audit log**, or **Observability** pages, Microsoft Entra setup, or their CSV export controls. Scope identity integrations, organization-wide audit requirements, and monitoring exports with the deployment team. See [Deployment models](/deployment-models).

## Troubleshooting

<AccordionGroup>
  <Accordion title="I cannot open Fluso Admin">
    Use the address and account authorized by your deployment operator. A personal subscription or ordinary organization membership does not grant panel access.
  </Accordion>
  <Accordion title="A dashboard cannot load data">
    Retry the view. If it stays unavailable, contact the deployment operator with the failing page and time. Do not interpret a failed request as an empty account or zero usage.
  </Accordion>
  <Accordion title="A runtime control is unavailable">
    Check its current state and ongoing work. Retry after the blocking condition clears; the panel does not force-stop active work.
  </Accordion>
</AccordionGroup>
